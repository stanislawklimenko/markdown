# Управление временем и скоупом (Time & Scope Management)

**Исходный план (2 недели, 2 инженера):**  
- Неделя 1: настройка инфраструктуры (Docker, Kafka, Qdrant), реализация базового пайплайна (анонимизация + классификация) на синтетических данных.  
- Неделя 2: интеграция RAG и LLM-генерации, реализация шлюза уверенности, написание документации и подготовка PoC-демо.

**Что пошло не по плану:**  
- Интеграция с OpenAI API заняла на 2 дня больше из-за необходимости обработки rate limits и реализации retry-механизма.  
- Настройка Qdrant с гибридным поиском (BM25 + векторы) потребовала дополнительного времени на настройку индексов.

**Сознательно вырезано из скоупа:**  
- Полноценный fine‑tune классификатора (заменён на few‑shot и готовые эмбеддинги) — чтобы не тратить время на разметку данных.  
- Мультиязычная поддержка (оставлена только английская версия) — для PoC достаточно одного языка.  
- Production‑мониторинг и дашборды (оставлены только JSON-логи) — фокус на функциональность, не на наблюдаемость.

**Итог:** Все ключевые функциональные блоки реализованы, два сценария (happy и fallback path) работают. Сдвиг на 2 дня компенсирован сокращением несущественных для PoC элементов. Worklog полностью соответствует коммитам в репозитории.
